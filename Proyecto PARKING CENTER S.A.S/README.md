🚘🛵🚒 Sistema de Control de Parqueadero:

Este proyecto grupal consiste en un sistema básico de gestión de parqueadero enfocado unicamente en Back - end , diseñado como simulador de capacitación para nuevos empleados.
Permite registrar el ingreso y salida de vehículos, calcular el tiempo de estadía y determinar el costo del servicio según el tipo de vehículo.

💡 Características principales:

Registro de ingresos y salidas: Captura la fecha y hora de entrada y salida de cada vehículo.

Cálculo de estadía: Soporta horas, minutos, días y meses, con una estadía máxima de hasta un año.

Cálculo de tarifas: Aplica tarifas diferenciadas según el tipo de vehículo: carro, moto o camioneta.

📋 Historial de vehículos:

Vehículos que han pasado por el parqueadero.

Vehículos que están actualmente en el parqueadero.

vehículos que han salido del parqueadero y han generado ingresos acumulados.

Validación de placas: No permite duplicar placas dentro del sistema, garantizando la integridad de los datos.

▶️ Cómo ejecutar:

Tener Python 3.10 o superior instalado.

Clonar el repositorio:

git clone https://github.com/Sergio-Bustos/Proyecto-Parking-Center-S.A.S


Y ejecutarlo en la terminal (preferiblemente VS CODE)

python main.py

🎯 Objetivo:

El sistema simula el funcionamiento de un parqueadero real, sirviendo como herramienta de aprendizaje para nuevos empleados y como base para proyectos de software de gestión.

Además, busca replicar un entorno cliente-desarrollador, promoviendo el trabajo en equipo, la investigación y el aprendizaje continuo en el desarrollo con Python.
