🍰 Proyecto ReposteryFlow SENA

📌 Objetivo;

Este repositorio contiene la aplicación web de ReposteryFlow un emprendimiento creado por aprendices del SENA Nuestro objetivo es ofrecer productos de panadería y repostería de alta calidad combinando técnicas tradicionales con un enfoque moderno en la personalización de pedidos y la selección de ingredientes

📂 ESTRUCTURA DE ARCHIVOS;

La información del sitio web está organizada en los siguientes módulos

Archivo bienvenida.html Contenido; Portal de Inicio, Descripción, Presentación de la marca, y sección de preguntas frecuentes FAQ.

Archivo carrito.html Contenido; Catálogo de Productos, Descripción, Galería visual de productos de Panadería, y Repostería con precios.

Archivo contactanos.html Contenido; Contacto y Pedidos, Descripción, Formulario para realizar pedidos, información de contacto, y métodos de pago.

Archivo enviado.html Contenido; Confirmación de Envío, Descripción, Mensaje de éxito mostrado después de enviar un pedido o consulta.

Archivo historia.html Contenido; Nuestra Historia, Descripción, Detalle sobre el origen del emprendimiento, la influencia del SENA y nuestros valores.

Archivo patrocinadores.html Contenido; Socios y Apoyos, Descripción, Información sobre las entidades y empresas que nos brindan soporte.

💻 TECNOLOGÍA UTILIZADA;

- Tecnología Base HTML5 para la estructura de todos los documentos

- Framework Bootstrap para el diseño responsive la navegación y los componentes visuales
